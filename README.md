# Brick Game Car

Jogo de corrida estilo Brick Game no terminal, em C (Windows e Linux).

- `brickgamecar.c` — versão 1
- `brickgamecar_v2.c` — versão 2
- [`enunciado/`](enunciado) — fotos do enunciado
- [`referencias/`](referencias) — `Unit1.pas` (versão original em Pascal) e `xadrezteste.c`

```bash
gcc -Wall -std=c99 -o brickgamecar brickgamecar_v2.c
```
