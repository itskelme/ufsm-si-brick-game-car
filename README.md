# Brick Game Car

**UFSM · Sistemas de Informação · 2026/1**

Jogo de corrida no estilo dos minigames Brick Game, no terminal, em C. Roda no Windows (`conio.h`) e no Linux.

| Arquivo | |
|---|---|
| `brickgamecar.c` | Versão 1 |
| `brickgamecar_v2.c` | Versão 2 |
| [`enunciado/`](enunciado) | Fotos do enunciado do trabalho |
| [`referencias/`](referencias) | `Unit1.pas` (versão em Pascal usada como base) e `xadrezteste.c` |

```bash
gcc -Wall -std=c99 -o brickgamecar brickgamecar_v2.c
./brickgamecar
```
